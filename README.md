# 🍽️ yemekhane-cdn

Репозиторий со статическими изображениями блюд столовой, подготовленными для использования в мобильном приложении.

Изображения оптимизированы и разделены по размерам для удобной и быстрой загрузки.

---

## 📂 Структура

- `thumb/` — используется для списков, карточек и предварительного отображения  
- `full/` — используется для детального просмотра  

---

## 📦 Содержимое

- Изображения блюд, разделённые на 2 размера
- Исходники скачаны с официального сайта университета
- Выполнен AI-upscale
- Оптимизация и конвертация в формат **JPEG**
- Подготовлены для раздачи через **jsDelivr CDN**

---

## 🎯 Назначение

Репозиторий используется как статическое CDN-хранилище изображений.

Разделение на `thumb` и `full` позволяет:

- ускорить загрузку списков (подгружаются лёгкие миниатюры)
- экономить трафик
- улучшить UX за счёт быстрой первичной отрисовки
- упростить архитектуру (JAMStack-подход)

---

## 🛠 Pipeline обработки

1. Загрузка изображений с сайта университета  
2. AI-upscale  
3. Подготовка двух размеров (thumb / full)  
4. Сжатие и конвертация в JPEG  
5. Загрузка в GitHub  
6. Раздача через jsDelivr  

---

## 📌 Примечание

Репозиторий используется исключительно как хранилище изображений и не содержит backend-логики.
